## 1. 通用原則

- **HP 同飽肚值拆開**：現有 `pet.health` → 改名為飽肚值（fullness）；新增獨立 HP。
- **HP 上限** = 戰鬥引擎 `stats.hp`（跟等級、性格變）。
- **HP 儲存**：DB 存千分比整數 `hp_permille`（0–1000），唔存實數。
  - 前端顯示：`round(hp_permille/1000 × stats.hp)`；`hp_permille > 0` 但換算為 0 → 顯示 1。
  - 升級／進化後比例不變，自動跟新上限。
  - 戰鬥開始時換算成實數；戰鬥結束換返千分比交 server。
- **單一主要狀態**：燒傷、麻痹、睡眠、冰凍、中毒（含嚴重中毒）同時只可一種，跟原作。例外見 §4.4。
- **嘔吐唔係 debuff**：一次性扣血，無圖示，唔受單一狀態限制。
- **Server 權威**（分兩期，見 §10）。戰鬥狀態只喺戰鬥**正常結束**時寫入；中斷（斷線／關 app／閃退）不保存，回到戰前狀態（包括用藥同 HP）。
- **戰後保留**：戰鬥結束時嘅 HP、主要狀態、Faint 全部保留（唔自動回復）。
- **離線照計**：server 記時間戳，開頁面時按經過時間結算。
- **Faint**：只可用活力碎片（現有 `revive` / Revival）復活 → HP 100%、飽肚值 100%、清除所有狀態。傷藥／好傷藥對 Faint 無效。
- **Faint 唔可以揀入出戰隊伍**（所有戰鬥模式）。

### 1.1 拍檔 vs 非拍檔

| | 當前拍檔 | 非拍檔 |
|---|---|---|
| 飽肚值下降 | 照常 | 凍結（同現有一樣） |
| 狀態戰後扣 HP（燒傷／中毒） | 照扣 | **唔扣** |
| 睡眠／冰凍 30 分鐘自然解除 | 照計 | 照計（時間戳計算，同拍檔一樣）※ |
| 狀態帶入戰鬥 | 會 | 會 |

※ 非拍檔睡眠／冰凍計時：負責人未明確講，預設照計；如有異議再改。

## 2. 飽肚值

| 項目 | 數值 |
|---|---|
| 下降 | 100% 約 25 小時歸 0（每小時 −4%，即每 15 分鐘 −1） |
| Normal food | +25% |
| Super food（premium） | +50% |
| 燒傷時 | 下降 ×1.5（每小時 −6%） |
| **歸 0** | 即刻 Faint：**HP 同時變 0**，答題 EXP 0，唔可以出戰 |

### 2.1 嘔吐階梯

| 次數 | 觸發 | 效果 |
|---|---|---|
| 1：嘔吐 | 餵**之前**飽肚值已 100%，再餵 1 粒 | −25% maxHP |
| 2：嚴重嘔吐 | 嘔吐後飽肚值仍 100%，再餵 1 粒 | 再 −25% maxHP |
| 3：Faint | 嚴重嘔吐後飽肚值仍 100%，再餵 1 粒 | HP 歸 0 |

- 只計「餵之前已 100%」；補到 100% 唔算。
- HP 不足 25% 時被扣 → 直接 Faint。
- 飽肚值跌到 100% 以下 → 計數重置。
- 「嘔吐」「嚴重嘔吐」只用嚟顯示唔同提示字句；飽肚值本身唔受嘔吐影響。

### 2.2 餵食 streak 取消

- 移除 `pet.streak`、`pet_last_fed_day`、「Fed today / Not fed today」。
- 育成彈窗原本 🔥 數字改為**連續答題日數**，icon 改用主頁同款閃電（`home-streak-bolt`）。

## 3. 藥物

### 3.1 種類（共 7 種新藥 + 現有活力碎片）

| 藥 | 效果 |
|---|---|
| 傷藥（Potion） | 回 25% maxHP |
| 好傷藥（Super Potion） | 回 50% maxHP |
| 解毒藥（Antidote） | 解中毒＋嚴重中毒 |
| 燒傷治療藥（Burn Heal） | 解燒傷 |
| 麻痹治療藥（Paralyze Heal） | 解麻痹 |
| 醒睡藥（Awakening） | 解睡眠 |
| 解凍藥（Ice Heal） | 解冰凍 |
| 活力碎片（現有 revive） | Faint 專用，見 §1 |

- 戰鬥同育成效果一樣；回復藥只回 HP，唔解狀態。
- HP 已滿再用：照樣消耗並計入過量。
- 戰鬥中用藥**佔一個回合**；**每場無用藥上限**。
- Inferno 嘅 Full Restore（玩家）**移除**。AI Potion 去留未定（見 §11）。
- 萬靈藥（Full Heal）今次唔做。

### 3.2 掉落（暫時只靠答題）

- 10/10 全對：穩掉 1 隻藥；1–9 題：10% 掉 1 隻藥。
- 掉落時 7 種平均抽（各 1/7）。
- 同現有 food / premium / revive / 進化石掉落並存。

## 4. 用藥過量／中毒

### 4.1 觸發（所有藥都計，包括治療藥同回復藥；活力碎片未定，見 §11）

| | 育成 | 戰鬥 |
|---|---|---|
| 中毒 | 1 分鐘內用 3 次藥 | 5 回合內用 3 次藥 |
| 嚴重中毒 | 中毒期間再 3 次 | 同左 |
| Faint | 嚴重中毒期間再 3 次，或 HP 扣到 0 | 同左 |

**窗口方式：滑動窗口**
- 育成：記最近用藥時間戳，第 1 次同第 3 次相隔 < 60 秒即觸發。
- 戰鬥：記每次用藥嘅 `state.turn`，最近 3 次落喺 5 回合內即觸發。

### 4.2 中毒效果

| | 育成／戰後 | 戰鬥內 |
|---|---|---|
| 中毒 | −1% maxHP／分鐘 | 現有 poison：1/8 maxHP／回合 |
| 嚴重中毒 | −2% maxHP／分鐘 | 1/4 maxHP／回合（現有 ×2） |

- 無時限，要解毒藥先停；扣到 0 → Faint；離線照計。
- 嚴重中毒**只由用藥過量觸發**。
- 敵方招式造成嘅中毒：普通中毒維持普通；劇毒招（Toxic）照引擎現有 toxic 遞增規則。戰後 toxic 一律轉為**普通中毒**。

### 4.3 中毒期間

- 傷藥可回血延遲 Faint，但唔解毒。

### 4.4 同其他狀態互動

| 情況 | 育成 | 戰鬥 |
|---|---|---|
| 已有燒傷／麻痹／睡眠／冰凍 | 過量 → **覆蓋**為中毒，原狀態連帶效果取消（如燒傷飽肚值 ×1.5） | **唔覆蓋**；改為一次性扣血：第 1 次 −25%、第 2 次 −25%、第 3 次 Faint |
| 冇其他狀態 | 照 §4.2 | 照 §4.2（真中毒，戰後保留） |

## 6. 麻痹

| 項目 | 規則 |

| 餵食 | **不可**（Normal／Super 都唔得），因此唔會嘔吐 |
| 飽肚值 | 照常 −4%／小時 |

## 7. 睡眠

| 項目 | 規則 |
|---|---|
| 戰鬥內 | 中招時 1–3 回合（現有）；**帶住睡眠出戰入場時重新抽 1–3 回合** |
| 戰鬥內醒咗 | 就係醒咗，戰後無睡眠，30 分鐘計時清除 |
| 自然醒 | 戰鬥結束寫入 server 嗰刻起計 30 分鐘；離線照計 |
| 出戰 | 可以 |
| 戰後扣血 | 無 |
| 餵食 | **不可** |
| 解除 | Awakening |

## 8. 冰凍（新，當睡眠咁處理）

| 項目 | 規則 |
|---|---|
| 戰鬥內 | 沿用現有：每次出招 20% 解凍 |
| 帶住冰凍出戰 | 戰鬥內仍然冰凍，照 20% 規則 |
| 戰鬥內解凍 | 就係解咗，戰後無冰凍 |
| 自然解凍 | 戰鬥結束寫入 server 起計 30 分鐘；離線照計 |
| 戰後扣血 | 無 |
| 餵食 | **不可** |
| 解除 | Ice Heal（戰鬥同育成都用得，計入過量） |

## 9. 混亂（修 bug，唔帶出戰鬥）

- 改為臨時效果（`volatile.confusion`），唔再佔主要狀態。
- 2–5 回合；每次出招 50% 自傷 1/8 maxHP（現有數值）。
- 換 Pokémon 或戰鬥結束即清除，**唔寫入 server**。

## 10. 實作分期（Server 權威）

### 第一期

- **Migration**：
  - `user_entries` 新欄位：`fullness`（由 `pet_health` 搬）、`hp_permille`、`status`、`status_since`（睡眠／冰凍計時起點）、`poison_level`、過量計數／時間戳、嘔吐計數、時間錨點。
  - `user_account` 新增 7 種藥數量欄位。
  - 所有可寫欄位同一份 migration 加 column-level grant（Rule 54）；若改為只經 RPC 寫，則唔 grant update。
  - 刪 `pet_streak`、`pet_last_fed_day`、`pet_settled_day`、`pet_decay_day`。
- **RPC**：餵食、用藥、離線結算（開頁面時呼叫，按經過時間計飽肚值、燒傷／中毒扣血、睡眠／冰凍到期）。
- **戰鬥**：`settle_battle_v2`（及好友對戰 settle）一次過寫入每隻出戰 Pokémon 嘅 `hp_permille`、`status`；戰中用藥數量一併扣。
- **前端**：只顯示；頁面開住時每分鐘自行推算更新，以 server 回應為準。

### 第二期

- PvP 雙方結算核對（防竄改）。

### 遷移（alpha，唔考慮舊玩家 UX）

1. `pet_health` → `fullness`。
2. 所有 entry `hp_permille = 1000`、無狀態；舊 `pet_health = 0` 嘅 → `hp_permille = 0`（Faint）。
3. 刪舊欄位（見上）。
4. 每個玩家送測試藥包：傷藥 ×3，其餘 6 種各 ×1。
